# Rodrigo Battagliero — CV Online

Personal CV website of **Rodrigo Battagliero**, Software Developer & Technical Lead from La Rioja, Argentina. A bilingual (EN/ES), fully static site deployed on Cloudflare Pages with zero build step and zero dependencies — plus one serverless feature: an AI chat assistant ("Ask my CV") powered by Cloudflare Workers AI that answers recruiters' questions about the resume.

**Live site:** [English](https://rodrigo-battagliero.pages.dev/) · [Español](https://rodrigo-battagliero.pages.dev/es/)
